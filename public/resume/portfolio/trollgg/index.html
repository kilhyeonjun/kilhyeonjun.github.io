롤전적 검색 OP.GG 클론코딩

GitHub

프로젝트 설명

Spring Boot를 공부하고 싶어서 좋아하는 게임인 League of Legends의 전적 검색 사이트 OP.GG를 클론 코딩하였습니다. Riot API를 사용하여 연동하였습니다.

주요 내용

  • Riot API 연동
  • Spring Boot 기반 웹 애플리케이션
  • Bootstrap을 이용한 반응형 UI

담당 기능

  • 전적 검색 기능
  • 랭킹 페이지

깨달은 점

  • 💡 외부 API를 사용하면 토큰을 사용하여 데이터를 수집할 수 있다
  • 💡 MVC 패턴을 사용하여 비즈니스 로직과 view, controller를 분리할 수 있다

기술 스택

Java Spring Boot MariaDB Bootstrap
